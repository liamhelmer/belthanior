## ADR-013: Sandboxed Credential Injection (commit cd69d84)
- Written and committed: `docs/adrs/ADR-013-sandboxed-credential-injection.md`
- Motivated by: discord_approval shipped with broken WASI HTTP because QA had
  no live credentials to test with; bot_token visible in MCP calls/logs
- Design: `constraints.secrets` + `constraints.env` in manifest → WASI env vars
  injected at invocation AND build/QA time
- Phased: v1 = girt-local.toml [secrets] + WasiCtxBuilder injection;
  v2 = QA live API testing; v3 = zero-knowledge HTTP proxy
- `constraints.secrets` field already existed in manifest schema (was unused)
- Original `host_auth_proxy` design in 001-girt-technical-design.md aligns with this
