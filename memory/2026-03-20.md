## Matrix Homeserver Decisions

### Architecture
- **Tuwunel**: conduwuit successor, Swiss government backed, full-time devs — enterprise pitch
- **Continuwuity**: community-driven conduwuit continuation, explicitly prioritizing Draupnir/policy list support, weekly releases
- Both single binary swap from conduwuit
- **ZeroClaw homeserver** comparison only, not Matrix-related

### Agent Identity on Matrix
- Application Services (Appservices) = the right primitive for multi-regional agent identity
- One appservice owns `@agent-*:*.work.com` namespace, receives all events, responds as any regional identity
- Policy Servers (MSC4284, late 2025): pre-delivery access control — homeserver asks "should I accept this?" before delivering
- Policy Rooms (MSC2313): append-only distributed rule database
- Draupnir = reactive moderation bot (after-the-fact), Policy Server = proactive gatekeeper
- Context7: MCP server (upstash/context7), not a skill — `npx ctx7 setup --claude` for installation

### Deployment
- Dance community: cheap VPS (~€4-10/mo Hetzner), Tuwunel, Cloudflare Tunnel, boring reliability
- Agent comms: belthanior (local, fast, downtime acceptable)
- Both federate — same Matrix ecosystem, different SLAs
- GCP option: e2-small VM + Container-Optimized OS + Tuwunel Docker + persistent disk = ~$17-21/mo

## discord-pipe Project (Epiphytic/discord-pipe)

### Status (in progress as of this flush)
- Repo: https://github.com/Epiphytic/discord-pipe
- Branch: `feat/full-implementation`
- Architecture: native Rust binary (no WASM), stdin + file-tail input, hybrid batching, ureq HTTP, token bucket rate limiting
- jcode running implementation via subagent-driven-development skill
- Progress: Phases 1-5 complete as of flush (ANSI stripping, formatting, batch buffer, overflow splitting, token bucket)
- Raw trace: `/tmp/discord-pipe-impl-raw.txt`
- Profile: `/tmp/discord-pipe-impl-profile.txt`

### Decisions
- No WASM (removed entirely, not deferred)
- Both stdin AND file-tail from day 1 (`--follow <path>`)
- ANSI stripping on by default (`--no-strip-ansi` to disable)
- Batching: 2s time window + 50 lines + 1800 Unicode codepoints (hybrid triggers)
- HTTP: ureq blocking, two-thread producer/consumer, sync_channel(50) back-pressure
- Overflow: 3 messages max, middle truncated with "N lines omitted"
