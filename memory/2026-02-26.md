
## Voice Escalation Response Pattern (IMPORTANT)
- When responding to voice escalations from Chip, do NOT end with NO_REPLY
- Do NOT use the `tts` tool — Chip handles TTS through its own pipeline
- Reply with the actual spoken text as the message body (short, speech-friendly)
- Separately post detailed response to Discord via `message` tool
- The gateway returns my text reply to Chip's escalation worker for TTS synthesis
- If I say NO_REPLY, Chip gets nothing to synthesize and the user hears silence
