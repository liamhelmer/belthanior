3. After restart: Liam needs to re-engage to start a new session
4. Never restart the gateway from a sub-agent — it kills the parent session

**Never do:** Have a sub-agent restart the gateway without explicit instruction from Liam.

1. **Corrections should be written to AGENTS.md immediately** (as a "Common Mistakes" section or amendment to the relevant rule)
2. **End-of-session memory flush should be mandatory**, not "every few days during heartbeats"

Without these changes, Bel will continue to repeat the same mistakes because the correction signal never reaches the files that persist across sessions.
