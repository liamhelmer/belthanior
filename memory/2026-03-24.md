## openclaw-fabric-plugin rewrite (completed ~00:09 PDT)

### Problem identified
The plugin was built with the wrong OpenClaw plugin SDK API:
- Used `export async function register(context)` — wrong
- Command names had spaces: `"fabric watch"`, `"fabric history"`, `"fabric logs"` — invalid (spaces not allowed)
- Handler key was `execute`, should be `handler`
- Args were typed as `Record<string,string>` — real API passes raw string `ctx.args`

### Correct SDK pattern
```ts
export default function register(api) {
  api.registerCommand({
    name: "fabric-history",   // kebab-case, no spaces
    acceptsArgs: true,
    handler: async (ctx) => {
      // ctx.args = raw string after command
      return { text: "..." };
    },
  });
  api.registerService({ id: "...", start: async () => {}, stop: async () => {} });
}
```

### Fix
- Rewrote `src/index.ts` to use correct SDK
- Commands now: `/fabric-watch`, `/fabric-history`, `/fabric-logs`
- Build clean, gateway restarted, plugin registered
